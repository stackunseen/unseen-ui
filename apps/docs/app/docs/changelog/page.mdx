# Changelog

Unseen UI is an experimental alpha. Prereleases are published on npm under the `alpha` tag; pin exact versions. Newest first.

## 0.1.0-alpha.11 — 22 October 2026

### Upgrade notes

- **Status text is capitalised.** Badges and status lines read "Connected", "Passed", "Permission requested" and "Medium risk" instead of the raw values ("connected", "Permission: requested", "medium risk"). Tests that look for the old text need the new words.
- **ModelSelector** shows its search field only for more than seven models; pass `searchable` to keep it. Provider headings show only when models come from more than one provider.
- **Compact ThreadList** rows are 36px including their borders, 1px apart (were 38px and 4px).
- **WorkspaceShell** panes take their padding and scrollbar room from `--ai-workspace-pane-padding` and `--ai-workspace-pane-gutter`. If you overrode the old 4px padding with a more specific selector, set the variables instead.
- **Chat replies** in the chat message variant render Markdown at the message size (16px) rather than the interface size (14px).
- **PromptInput** no longer shows "Shift + Enter for a new line" by default; screen readers still hear it. Pass `hint` to show a line.
- **The assistant icon** (`AIIcon name="assistant"`) is a speech bubble instead of a magic wand. Chat and ModelControls headers no longer show a decorative icon before their titles.
- **RunBoard** with `variant="list"` shows runs as rows divided by lines, with a sentence-case group heading, instead of a bordered card per run. Board and compact variants are unchanged.
- **DateRangePicker** joins a selected range with an en dash ("Thursday, February 1, 2024 – Saturday, February 3, 2024", was an em dash) and reads "Thursday, February 1, 2024. Choose the end date" while picking.
- **Overlay content has no wrapper div.** Modal, AlertDialog, Popover, Tooltip, DropdownMenu, ContextMenu and Select content now carry the theme scope (`data-ai-theme`, `data-appearance`) themselves instead of sitting inside an extra div in the portal. Selectors that reached the content through that wrapper need updating.
- **Closed menus fade out.** Force-mounted DropdownMenu and ContextMenu content is hidden by its exit animation and made inert, instead of `display: none`.

### Changes

- **Chat:** `onEdit` lets people rewrite a sent message; `branches` and `onBranchChange` show "‹ 1/2 ›" to switch between versions after an edit or a regenerate; `feedback` and `onFeedback` rate any reply; `renderMessageActions` adds actions such as Read aloud; `emptyContent` replaces the start screen. Copy and rating now appear under every finished reply (earlier ones on hover), with Regenerate on the last.
- **Messages:** new `reasoning` and `file` parts. Reasoning shows as a "Thinking…" disclosure that collapses when the answer arrives; attached images show as thumbnails and other files as a chip. The AI SDK mapping fills them in; reasoning stays hidden unless you pass `reasoning: 'show'`, and only http(s) or base64 PNG, JPEG, GIF and WebP images are shown inline.
- **Sources:** web sources from the AI SDK follow the reply, and neighbouring sources share one row of chips.
- **Modal:** `trigger` is optional, for dialogs opened from a menu or a keyboard shortcut. Without a trigger, closing returns focus to whatever opened it, whether the host closes the Modal or stops rendering it.
- **WorkspaceShell:** `navigationMode="responsive"` adds a navigation toggle. Wide layouts collapse the navigation column; narrow ones show it as a drawer that takes focus, closes on Escape, the scrim or a followed link, and returns focus to the toggle. Control it with `navigationOpen` and `onNavigationOpenChange`; `navigationBreakpoint` sets the width. Crossing the breakpoint closes the navigation on the way down, so phones start on the content, and reopens it on the way up. `headerPlacement="main"` puts the header above the main content only, with navigation running the full height, as in chat apps.
- **PromptInput and Chat:** `commands` and `mentions`. Typing "/" at the start of a message, or "@" after a space, opens a list above the composer, filtered as you type: arrow keys move, Enter or Tab picks, Escape closes, and the textarea announces it as an autocomplete list. A command removes the typed "/word" and calls `onCommand` with the remaining message; a mention inserts "@label " and calls `onMention`. `onMentionQueryChange` lets you search on your side, for example over files.
- **Chat and Message:** `messageVariant="chat"` on Chat (or `variant="chat"` on Message) shows your messages as right-aligned bubbles and replies as plain text, without avatars or speaker labels on screen; the speaker stays available to screen readers, and actions sit under the bubble. The "/" and "@" list now opens below the composer when there is no room above, and lists one option per line.
- **WorkspaceShell:** scrolling panes are positioned, so absolutely placed content inside them (such as a Select's hidden native control) stays in the pane instead of stretching the page.
- **PromptInput and Chat:** `hint` (PromptInput) and `composerHint` (Chat) replace the "Shift + Enter for a new line" line under the composer, for other languages or wording.
- **Times:** observed times (such as an approval's expiry or a timeline event) show in the viewer's time zone and locale once the page runs, with UTC in the tooltip. The server and the first render still show UTC, so both produce the same text.
- **Styling:** disabled filled buttons (primary, danger) turn neutral grey instead of a faded copy of themselves, other disabled controls fade to 50%, placeholders are lighter than typed text, and the search field's clear button uses the theme's grey.
- **Tabs:** `className` on the root, for sizing tabs in your layout (for example a fixed height in a settings dialog).
- **PromptInput:** the message box grows with its text up to its maximum height, then scrolls, so multi-line messages and quotes stay in view.
- **AI SDK mapping:** once the chat is idle, a tool call still receiving input or running reads as `cancelled`, so a reply stopped mid-tool no longer shows a stuck "receiving input" card.
- **MessageActions:** thumbs icons, filled once rated, so the chosen rating is visible; the confirmation reads "Feedback sent." A person's own sent message no longer carries a "Response complete" status.
- **RunBoard:** `hrefFor` makes each card title a link, so runs open in a new tab with Ctrl or Cmd; a plain click still calls `onSelect`.
- **RunBoard:** `hideLabel` keeps the board's name for screen readers only, for pages whose tabs or heading already say which list it is.
- **IconButton:** `icon` also takes your own icon component, such as one from `@radix-ui/react-icons`, with the same size, tooltip and required label as the built-in names.
- **PromptInput:** after a "/" command the caret goes to the end of the message, so words the host puts in front ("Create an image of ") come before what you type next.
- **Video** (`/media`): new. A generated video with the same states as Image: `queued`, `loading` with host-measured `progress` and a softened `preview` frame, `failed` with `error` and `onRetry`, and a player with native controls once ready. It never autoplays, needs a `label`, and refuses sources other than http(s) and blob:.
- **Group chats:** messages take an optional `author` (`{ id, name, you? }`), and the AI SDK mapping reads it from a user message's `metadata.author`. Someone else's message is labelled with their name ("Message from Ben") and carries `data-author="other"` for your styling; yours still reads as You.
- **ThreadList:** `searchable={false}` leaves out the search box, for a sidebar that searches in a dialog of its own. The compact variant's title now matches its date group labels.
- **WorkspaceShell:** a class that sets the shell's height, such as `height: 100dvh`, now takes effect with the default pane scrolling, so navigation footers stay in view.
- **MarkdownResponse:** `citations` turns `[1]`-style markers in the text into citations that open their source. Markers inside code, and numbers without a source, stay as written.
- **Image:** generation states: `queued`, `loading` with host-measured `progress` and a softened partial `preview`, and `failed` with `error` and `onRetry`. Progress shows only when the host measured it.
- **Tabs:** `orientation="vertical"` lists tabs beside the panel, as settings dialogs do, with up and down arrow keys; it stacks in narrow containers.
- **ChatLauncher** (`/chat`): new. A floating chat bubble for websites that opens a non-modal chat panel (full screen on phones), focuses the composer, keeps the conversation mounted while closed, shows unread replies and returns focus to the bubble.
- **SuggestTextarea** (`/assistant`): new. AI completion as ghost text after the caret; Tab accepts and Escape dismisses only while a suggestion shows, and screen readers hear it as a description. The host supplies suggestions.
- **FileExplorer:** files take optional `lines: { added, removed }`, shown as a DiffStat beside the change badge, so the list view doubles as a changed-files list.
- **ThreadList:** `actions` puts controls such as New chat beside the title; `groupBy="date"` groups threads into Pinned, Today, Yesterday, Previous 7 days, Previous 30 days and Earlier from the new optional `updatedAt` and `pinned` fields on `ThreadSummary` (pass `now` so server and browser agree); `rowActions` adds your own per-thread controls. `groupThreadsByDate` is exported. The compact variant is now a sidebar list: one line per thread with long titles cut short, no card backgrounds, and actions that appear on hover or keyboard focus (always on touch), staying put while their menu is open.
- **RunBoard:** `renderCardTrailing` adds content at the end of each card's title row, such as a DiffStat, so the list variant works as a coding-agent task list.
- **WorkSummary** (`/assistant`): new. The steps of one agent turn, open while it works and collapsed to "Worked for 15s" once done ("Stopped after", "Failed after"), with room for a log underneath.
- **DiffStat:** new. "+15 −1" for a change, with an optional file count and proportion blocks, read as "15 lines added, 1 removed".
- **ElapsedTime:** new. Time spent on a run or turn ("2m 05s"), ticking while it runs and fixed once it ends, without interrupting screen readers. `formatElapsed` is exported too.
- **Checkbox, Switch, RadioGroup:** `label` (and `description` for Checkbox and Switch) label the control without a separate Field. Checkbox and Switch render their own horizontal Field; RadioGroup renders the label as its legend. Keep using Field when you need an error message.
- **Icons:** `more`, `attach`, `sidebar`, `globe`, `newChat` and a real `microphone` glyph for IconButton.
- **ToggleGroup:** an option's `description` is now announced as a description, so the button's name stays "Search" rather than "Search Search the web".

- **AI SDK approvals:** the card is titled with the tool row's label (from `describeTool`), its wording changes once you approve or reject, and the summary line shows only what is known. Unassessed risk and missing scopes are stated under Details instead.
- **Types:** `Step`, `MessageData`, `ToolCallData`, `ApprovalProposal`, `Source`, `Measurement` and the other data shapes that props use now export from `@stackunseen/ui`, so apps need only that package.
- **EmptyState:** takes `title`, `description`, `icon` and `actions` directly; the composed parts still work.
- **SplitPane:** a responsive pane that stacks on a narrow screen now shows both panels at their natural height instead of collapsing to nothing.
- **Quieter output:** TerminalOutput no longer reports a missing session for a plain log or offers "Pause following" after the process ends; CodeDiff says "New file" or "Deleted" and skips the newline note for them; compact AgentSteps keeps progress in the marker instead of repeating a badge on every step; a low-risk approval no longer shows a warning icon.
- **Component manifest:** `@stackunseen/ui/manifest.json` lists every export of every entry, each component's own props (with overloads merged), the naming rules and every `--ai-*` CSS variable, generated from the published types. Coding agents and tools can read the API from it instead of guessing.
- **Design tokens:** a new [Design tokens](/docs/tokens/) page says what each `--ai-*` variable is for, with its light and dark values. Component pages gain "Good to know" notes on deliberate behaviour and an "All props" table.
- **Status in words:** MCPServerCard, MCPToolList, FileExplorer, EvidenceGroup, ContextBar, MemoryControls, AgentHandoff, Commit, PackageInfo, ReviewChanges, TestResults, TerminalOutput, RunInspector, RunCompare, ApprovalCard and the mention picker show states as words; `auth-required` reads "Sign-in required".
- **Less repetition:** BackgroundStatus hides zero counts ("Nothing running" when idle); MessageQueue tags only rows that are not plainly queued; AgentSteps drops the badge on finished steps; ScopeGrant no longer repeats "Expired" beside its badge and says "Uses not counted" with the reason; Attachment shows "CSV · 24.0 KiB" instead of "text/csv" and announces Ready without showing it; CodeTabs with `copy` shows one copy button; ApprovalBatch, DryRunPreview and ScopeGrant meta lines are split by middle dots.
- **ModelSelector:** each model on a row with its description and a check beside the current one, instead of radio circles; the menu opens aligned to its button.
- **Layout:** ArtifactDiff puts the two versions side by side; RunCompare row names align to the start; CodeDiff rows run to both edges of the card; the chat message action row sits right under the reply.
- **Sidebars:** compact ThreadList actions are never taller than their row, so hovering never moves the list. `--ai-list-inset` lines rows up with a host's navigation and `--ai-navigation-gutter: auto` drops the list's own scrollbar room when it grows inside another scroller.
- **CodeDiff:** `annotate` places notes under a line, spanning both columns in the split view. Changed lines keep code in the text colour; the tint and the + or − marker show the change.
- **RunBoard:** list rows sit on two lines, with times in the viewer's time zone.
- **Select:** ignores the empty value a form's hidden native select reports, so a choice no longer resets to the placeholder.
- **FileExplorer:** shows only the metadata the host supplied, as plain rows with dividers.
- **Text:** dialogs are centred without transforms, so their text stays sharp; the default font stack uses Segoe UI Variable on Windows 11. Set `--ai-font-family` to use a web font you load.
- **Radio options** are at least 24px tall with a mouse, so options without a description space like the rest.
- **Stylesheets:** `styles/core.css` plus one sheet per base entry (`styles/layout.css`, `styles/markdown.css` and so on) load less than `styles.css`, which is unchanged. Button always carries `data-button` for styling.
- **CodeDiff:** `showVersions={false}` hides the "base → next" line in the header, for pages that show several diffs of the same pair and state the comparison once. The versions still bind copies and feedback.
- **Touch screens:** hover styling applies only on devices that can hover, so a tap no longer leaves a button or row looking hovered. Inputs, textareas and the PromptInput box use 16px text on touch screens, so iOS Safari no longer zooms the page when they gain focus.
- **ClarificationRequest:** an empty text answer reads "Enter an answer to continue.", matching "Choose an answer to continue." for choices.
- **Overlay motion:** Modal and AlertDialog rise in with a light blur, Popover, Tooltip, DropdownMenu, ContextMenu and Select grow from the edge nearest their trigger, and backdrops fade. Each exit is shorter than its enter, and with reduced motion only opacity changes.
- **AppearanceToggle:** `variant="switch"`, a sun and moon pill with only light and dark, and `variant="subtle"`, one quiet icon that cross-fades between them. Both start from the system's choice while the value is `system`. The dark-mode glyph is now a plain crescent.
- **TableOfContents:** `variant="track"` lists every level on a line that steps in with each level and darkens for the sections on screen, ending in a dot. `variant="ticks"` is a slim rail of marks for long reads, the current section longest, that opens into the titles on hover, focus or a press.

## 0.1.0-alpha.8 — 19 October 2026

- **Chat:** a new `@stackunseen/ui/chat` entry with `Chat`, a complete chat surface, and `useLocalHost` for prototypes.
- **AI SDK:** `useAiSdkChat(useChat())` connects Chat to the Vercel AI SDK, with tool approvals shown as approval cards. `@stackunseen/ui-core/ai-sdk` has the mapping for custom layouts.
- **Shorter inputs:** Message accepts `{ role, text }`; ToolCall and ToolGroup accept `{ name }` plus what you know.
- **Compact by default:** ToolCall, ToolGroup, RunInspector, WorkflowGraph and ExecutionTimeline take `detail: 'compact' | 'full'` and hide revisions, durations and source lines unless asked.
- **Honest approvals:** ApprovalCard reads "Risk not assessed" and "None supplied" instead of invented values when the host has none.
- **Quieter defaults:** the default primary is neutral ink (`#171717`; pass `primary` for a brand colour), corners are 12px on panels and 10px on controls, and dark-mode field borders are softer while staying above 3:1.
- **Tool rows:** ToolCall `variant="row"` and ToolGroup `variant="list"` show one line per step with a host-written `label`, `target` and duration; messages and Chat use rows. The AI SDK mapping takes `describeTool` for those words.
- **Composer:** a round send button, the keyboard hint only while typing, and ModelSelector `variant="ghost"` for toolbars.
- **Decisions:** a decided ApprovalCard shows its outcome instead of disabled buttons; Combobox shows the chosen value in the field with an inline clear; ChainOfThought ticks finished steps and spins the active one.
- **shadcn registry:** `npx shadcn@latest add https://unseenui.com/r/chat.json` (or `@unseen/chat` with the namespace in `components.json`) installs `@stackunseen/ui` at the release and writes a starter. Items: `chat`, `chat-ai-sdk` (with `app/api/chat/route.ts`) and `theme`. They match `npx @stackunseen/ui init`.
- **More merges:** Workflow is `AgentSteps dependencies` (with `selectedId`/`onSelect`); MultiSelect is `Combobox type="multiple"`; ReasoningControl is removed (use `ToggleGroup variant="segmented"` or `Select`); OpenInChat is ShareMenu targets (custom targets now accept only http(s), mailto or relative links); Task is ChainOfThought (steps take a `failed` state, files are sources); LinkButton is `Button href`; Chip has no static form (use Tag); Shimmer and DataTable are internal (use DataGrid for application tables).
- **Merged components:** SegmentedControl is now `ToggleGroup variant="segmented"` (with `mode="links"` and option `description`); Chip keeps its link, removable and static forms, and choices move to ToggleGroup; LinkCard is `Card href` (with `external`); Panel and PanelHeader fold into Card, whose `Card.Header` takes `actions`.
- **Fewer, broader components:** Disclosure is removed (use Accordion with one item), ProgressRing is now `Progress variant="ring"`, and Kbd, SkipLink and VisuallyHidden are no longer exported (use a `<kbd>`, an anchor and your own screen-reader class). Stat draws each figure as its own card; `variant="plain"` keeps the bare figure.
- **Button:** `variant="link"` for text-like actions; DataGrid `captionVisibility="hidden"` for tables inside titled cards.
- **Site:** gallery and list views with live-preview thumbnails, search by meaning, task pages, Patterns in the navigation, an AI SDK recipe, this changelog, and `llms.txt` for coding agents.
