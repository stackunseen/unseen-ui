# Getting started

Build a small React interface, then add the components you need. Unseen UI is an experimental alpha; APIs may change between releases.

## 1. Install from npm

The packages are public on npm under the `alpha` tag. Your app needs React and ReactDOM `^19.3.0`, a bundler that supports CSS imports, and React types if you use TypeScript.

```sh
npm install @stackunseen/ui@alpha react@^19.3.0 react-dom@^19.3.0
```

`@stackunseen/ui-core` installs automatically as a dependency. Pin the exact version in your lockfile; the `alpha` tag moves with each prerelease.

<details className="setup-archives">
<summary>Work from the source repository instead</summary>

The source repository is private. With an authorized checkout, use **Node 24.13 or later within Node 24** and **pnpm 11.5.0**. From the repository root:

```sh
pnpm install --frozen-lockfile
pnpm build:packages
pnpm dev
```

Open [the development site](http://127.0.0.1:3000). Build the packages before starting a workspace consumer.

For the static website preview:

```sh
pnpm --filter @ai-interaction/docs build
node apps/docs/scripts/preview.mjs
```

Open [the website preview](http://127.0.0.1:4175). The preview serves the built site; rebuild the docs app after changing a page.

</details>

## 2. Render your first component

Import the base stylesheet once and wrap your interface in `AITheme`. In Next.js, this interactive example belongs in a Client Component; other React apps can use the same component.

<div className="setup-live-example" role="region" aria-label="First component example">
  <FirstExample />
</div>

This example keeps a draft and a saved name in memory. Nothing is sent or persisted. Copy it into a `.tsx` file and render `<FirstExample />` from your app:

```tsx
'use client';
import { useState } from 'react';
import { AITheme, Button, Field, Input } from '@stackunseen/ui';
import '@stackunseen/ui/styles.css';

export function FirstExample() {
  const [name, setName] = useState('');
  const [savedName, setSavedName] = useState('');
  return (
    <AITheme>
      <form
        style={{ display: 'grid', gap: 12, maxWidth: 360 }}
        onSubmit={(event) => {
          event.preventDefault();
          setSavedName(name.trim());
        }}
      >
        <Field label="Your name" required>
          <Input
            name="displayName"
            value={name}
            maxLength={80}
            onChange={(event) => setName(event.target.value)}
          />
        </Field>
        <Button type="submit">Save locally</Button>
        <p role="status">{savedName ? `Saved locally: ${savedName}` : 'Nothing saved yet.'}</p>
      </form>
    </AITheme>
  );
}
```

The value and callback stay in your application. To save to a server, replace the local update with your host's validation and receipt handling. Read [Connect to your app](/docs/integration/) before wiring tools, approvals or execution.

<h2 id="optional-renderers">3. Add only the entries you need</h2>

Ordinary controls come from `@stackunseen/ui`. DataGrid has a separate entry and stylesheet. Keep the base CSS and `AITheme` from the first example.

```tsx
import { DataGrid } from '@stackunseen/ui/application';
import '@stackunseen/ui/application.css';
```

Open the [DataGrid guide](/components/data-grid/) for controlled rows, sorting and paging. This entry needs no additional optional peers.

<details className="setup-entries">
<summary>Other optional entries and their dependencies</summary>

The paths below are subpaths of `@stackunseen/ui`. Install optional peers only for entries you import. The base React and ReactDOM peers are still required. Exact supported ranges are in the React package manifest included with the local build.

<OptionalEntries />

For example, a Markdown response needs these imports after installing its peers:

```tsx
import { MarkdownResponse } from '@stackunseen/ui/markdown';
import '@stackunseen/ui/styles.css';
```

Follow each component's usage guide for its required values and callbacks. There are no `/button` or `/icons` subpaths.

</details>
